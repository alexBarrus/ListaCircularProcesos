# Lista Circular de Procesos (Round-Robin)

Práctica de Estructuras de Datos: TDA Lista Circular doblemente enlazada (`primero`, `ultimo`, `siguiente`, `anterior`) programada desde cero, con el dominio modelado como `record Proceso(pid, nombre, rafaga)` y una interfaz Java Swing hecha con el GUI Builder de NetBeans.

- `BackEnd/Proceso.java` – record de dominio.
- `BackEnd/Nodo.java` – nodo con enlaces `siguiente` y `anterior`.
- `BackEnd/ListaCircular.java` – TDA: insertar, remover, mostrar, buscar y navegar en anillo.
- `FrontEnd/GUIListaCircular.java` + `.form` – ventana (se abre en el diseñador de NetBeans).

Abrir la carpeta en NetBeans como proyecto Maven y ejecutar (clase principal `FrontEnd.GUIListaCircular`, Java 25).
